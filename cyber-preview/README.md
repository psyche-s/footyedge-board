# FootyEdge Cyber Minimal · isolated Next.js preview

This directory is a **standalone test app**, deployed from branch \`design/cyber-minimal-nextjs-oct23\` into the separate Vercel project \`footyedge-cyber-lab\`. It does not replace the original static FootyEdge app, does not edit its GitHub workflows and does not alter V2 automation.

## Included

- Next.js App Router + React 19 + TypeScript + Tailwind 3 + Framer Motion + Lucide.
- Responsive one-third match picker and two-thirds analytics workspace.
- League-grouped cards with status, researched confidence out of 100 (NOT calibrated probability), and on-demand collapsible analytics.
- TacticalLineup that accepts an **actual externally supplied lineup** or an explicit, user-supplied **Arsenal design demo** with interactive xT/recoveries/fouls/SOT.
- No invented bookie odds, lines, xG, player metrics or current lineups. Empty / insufficient sources render N/A and a non-deceptive explanation.
- Archived 2026-10-23 FootyEdge fixture snapshot bundled as 11 KB \`src/data/dashboard.json\`.
- Optional Python ETL that outputs the same JSON schema for a future verified fixture window.

## Build static match snapshot

\`\`\`bash
pip install -r requirements.txt
python scripts/build_dashboard_data.py --seasons 2526,2627 --as-of 2026-10-23 --days 14 --output src/data/dashboard.json
\`\`\`

Football-Data.co.uk official season CSVs carry scores, shots and selected match stats; **they do not supply pre-match xG, lineup vectors or verified SGP prices**. The pipeline accepts optional pre-match xG/quoted-line CSVs and match-keyed, source-reviewed content:

\`\`\`bash
python scripts/build_dashboard_data.py \
  --xg-csv ./secure_exports/prematch_xg.csv \
  --shot-lines-csv ./secure_exports/quoted_shots.csv \
  --curated-json ./secure_exports/reviewed_fixtures.json
\`\`\`

The xG CSV columns are \`league,date,home,away,home_xg,away_xg\` and the shot-line CSV columns are \`league,date,home,away,metric,line,projected,as_of,provider\`; league here means Football-Data CSV code (e.g., E0, SP1). Input CSVs must be licensed/rights-cleared. FBref export data can be normalized separately when permitted, but this pipeline does not scrape FBref pages.

Curated JSON keys are the stable fixture IDs generated by SHA1 of source league code, local fixture date, normalized home and away club names. Reviewers can attach genuine XI and published market selections; the builder will not fabricate them.

**Important:** Some source CSVs list only finished matches, not upcoming fixtures. If verified future fixtures are absent, the ETL exits without overwriting the published dashboard. Provide a rights-cleared fixture CSV using \`--fixture-csv\` and \`--fixture-league\` when necessary. The current snapshot comes from existing FootyEdge research data, not from a live pipeline run.

## Vercel usage

The site renders directly from its small committed JSON file; no server-side scraping, API calls on route rendering, databases, timers, or runtime computation. To refresh it in the future, execute the ETL in a data pipeline and review/commit the resulting file to this design branch. **Do not enable scheduled refreshes or merge to main without explicit approval.**

The theme had an invalid seven-digit Serie A accent \`#0093ccc\`; it is normalized to valid \`#0093cc\`.
