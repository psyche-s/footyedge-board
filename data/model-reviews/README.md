# FootyEdge Original pick-model coherence

These are dated **diagnostics**, not corrections to frozen selections. The researcher strength grade is not a calibrated win probability; model probabilities and grades should never be conflated. Where an outright pick contradicts the simulation favorite, or the qualitative score substantially exceeds the model-market frequency, require an independent review before upgrading a bet. Missing player/lineup data remain missing, never zero.

For model evolution, train on verified completed fixture and prop outcomes only, with chronological train/holdout separation and a minimum of 50 observations for each market family. Validate Brier score, log-loss, model reliability and protected holdout results before changing simulation weights. Only promote a change if it improves actual out-of-sample calibration; do not alter numbers merely to match the tips already written. The official same-day board and past results remain immutable.
